# Security

Showpilot runs on your own computer: it opens the pages you configure in a local browser, and writes only to your
project's `out/` folder and `SHOWPILOT_HOME`. It sends nothing anywhere itself; the setup commands download the
browser, Python packages and the voice model from their official sources.

To report a vulnerability, use GitHub's **private vulnerability reporting** (Security → Report a vulnerability) on
this repository rather than a public issue. You'll get a reply within a week.
